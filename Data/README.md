# Frozen analysis inputs

The public reproduction workflow starts from the exact prepared inputs used
in the manuscript, not fresh raw downloads. Download the three RDS assets and
SHA256SUMS from the matching release of this same DCS-sPPM repository. The
release has not been uploaded by these tools. See [release instructions](../docs/DATA_RELEASE.md).

## Required assets

| File | Purpose |
| --- | --- |
| pm10_unique_locations_2024.rds | Final 2,989-location inventory, daily observations, imputed responses and selection metadata |
| era5_combined_2024.rds | Meteorological grid used for matching and covariates |
| production_30000_online_grid_preparation.rds | Fixed dates, scaling, station/weather matching, geographical settings and 5,297-point prediction grid |

These files are ignored by Git and uploaded as release attachments, not
ordinary Git commits. Historical fits are not needed. The earlier
pm10_combined_2024.rds and production_10000_single_chain_preparation.rds are
local historical resources, not inputs to the final production workflow.
Simulation data are generated by their own scripts.

## Installation without fitting

Download the matching release files into a temporary folder. From the code
repository root, using your actual download folder:

```powershell
python Tools/scripts/verify_frozen_inputs.py --input-dir C:/Downloads/DCS-inputs --checksums C:/Downloads/DCS-inputs/SHA256SUMS
```

Copy only the three validated RDS files into Data/. Do not replace an existing
input version without explicitly reviewing the change. Run:

```powershell
python Tools/scripts/audit_repository.py --require-inputs
Rscript Tools/scripts/validate_preparation_inputs.R
```

The R check validates 2,989 locations, 366 dates, 5,297 prediction sites,
response/covariate alignment and fixed initial values; it does not run MCMC.
Then follow [reproduction commands](../docs/REPRODUCIBILITY.md).

## Provenance and permissions

PM10/metadata originate from EEA Air Quality services and meteorology from
Copernicus ERA5. Retain source attribution and all applicable data terms.
The prepared inputs freeze the final location decisions, imputation,
meteorological matching, scaling and prediction support. They do not imply
that raw-download regeneration has been independently verified. The manuscript
must accurately describe the filtering and aggregation that produced them.

Raw preparation and historical selection code are archived locally outside
the public project; they are not needed to reproduce analyses from these
assets. Prepared inputs and fitted results have not been modified or deleted.
